Spin positions

スピンの基本の姿勢は、3つです。

アップライトは、立って回る姿勢です。滑っている脚を伸ばすか、少しだけ曲げて回ります。

シットは、しゃがんで回る姿勢です。滑っている脚の太ももを、氷と平行か、それより低くします。

キャメルは、上体を前に倒して回る姿勢です。浮かせた脚を後ろへ伸ばし、膝を腰より高く上げます。

姿勢を変えながら回るコンビネーションスピンは、3つの姿勢をすべて入れると、基礎点が満額になります。

Spins in a program

ショートとフリーには、スピンを3つずつ入れます。

3つのスピンは種類が決まっていて、跳んで入るスピンや、途中で滑る足を換えるスピンなどがあります。1つの姿勢は2回転以上続けて、はじめてその姿勢として数えます。足を換える時は、換える前と後でそれぞれ3回転以上回ります。

Levels

スピンとステップの基礎点は、レベルで変わります。

レベルは、B（ベーシック）と1〜4の5段階です。どの要素が行われたかを判定する技術パネルが、難しさを上げる決まった特徴をいくつ認めたかで決まり、1つでレベル1、4つでレベル4になります。

プラスαスピンの特徴には、難しい姿勢の工夫、跳んで足を換える、左右の向きに続けて回る、はっきり速くなる、1つの姿勢のまま8回転以上回る、などがあります。

Step sequence

ステップシークエンスは、リンクを大きく使って滑る要素です。

ターン（片足のまま向きを変える動き）とステップ（足を踏み替える動き）を、途切れずにつなぎます。レベルは、難しいターンとステップの種類の多さや、左右どちらの向きにも回ること、上体の動きなどで決まります。

Choreographic elements

コレオシークエンスは、決まった形の無い振り付けの見せ場です。

スパイラルやイーグル、イナバウアーなど、2種類以上の動きを音楽に合わせてつなぎます。レベルは無く、基礎点は決まった値なので、差は出来栄え点だけでつきます。

今シーズンから、フリーの3つのスピンのうち1つが、コレオスピンになりました。3回転以上続けて回れば姿勢は自由で、これも出来栄え点だけで評価されます。

見どころ

スピンの出来栄えは、速さと姿勢から

ジャッジは、スピンを次の6つの観点で見て、当てはまる数を出来栄えの段階の目安にします。+4以上をつけるには、最初の2つ（速さと姿勢）が欠かせません。反対に、回るうちに中心が流れていく「トラベリング」は、出来栄えを下げます。

  1. 回転が速い、または速くなる
  2. 姿勢がはっきりして安定している
  3. 楽に回っている
  4. 中心がずれない
  5. 独創性がある
  6. 音楽に合っている
見どころ

ステップの出来栄えは、エッジと音楽から

ステップシークエンスも、ジャッジは6つの観点で見ます。いちばん大事な最初の2つは、深いエッジで正確にターンを踏むことと、音楽に合っていることです。

  1. 深いエッジと正確なステップ・ターン
  2. 音楽に合っている
  3. 勢いがあり、楽に滑っている
  4. 上体の動きに独創性がある
  5. リンクを広く使う、面白い道すじ
  6. 加速と減速がはっきりしている
