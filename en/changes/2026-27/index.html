What Changed in 2026-27

What changed

The Free Skate’s structureand some base valueschanged this season.

The rules of figure skating are revised on July 1, at the start of each season. For 2026-27, the rules on how a program is built were revised, including the number of jumps allowed in the Free Skate and the number of jump combinations. The base values of elements such as spins were also raised.

Rule changes

The main rule changes

The number of jump elements allowed in the Free Skate went from 7 to 6. A skater must still include one Axel, as before.

The number of jump combinations allowed in the Free Skate went from 3 to 2. Only one combination of three jumps is allowed, as before.

Last season, a jump with a different number of rotations counted as a different jump. This season, the same kind of jump can be performed at most 3 times, whatever the rotations.

When the same triple or quad jump is performed solo twice, the base value of the second one is reduced. The reduction is smaller than last season.

One of the 3 spins in the Free Skate is now a choreographic spin, which shows off choreography. Any position is allowed as long as the skater keeps spinning for at least 3 rotations. Its base value is fixed, and only the grade of execution (GOE) moves the score.

The Euler is a small jump placed between the jumps of a combination. It no longer has a base value (it scores no points). It is now a “non-listed jump” (also called an excluded jump), which is not counted toward the number of jump elements.

Last season the Euler counted as one jump, so a combination with an Euler could have at most 2 scoring jumps. This season it can have 3 scoring jumps, so a combination of 4 jumps including the Euler is possible. It can be used only in the Free Skate, and at most once.

Base values

Base values went up for spins and sequences.

The base values of elements other than jumps were raised. For example, “Change-foot combination spin (level 4)” went from 3.50 to 4.20.

PlusThe Pairs Free Skate gains two new elements this season: the choreographic pair lift (base value 4.50) and the choreographic pair spin (base value 3.50).
