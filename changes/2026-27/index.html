2026-27 ここが変わった

What changed

今シーズンから、フリーの構成と要素の基礎点が変わりました。

フィギュアスケートのルールは、シーズンの始まりの7月1日に改正されます。2026-27シーズンは、フリーに入れられるジャンプの数や連続ジャンプの本数など、プログラムの構成に関わるルールが改正され、スピンなどの要素の基礎点も引き上げられました。

Rule changes

ルール改正の主な内容

フリーに入れられるジャンプは、7つから6つに減りました。アクセルを1つ入れなければならないのは、以前と同じです。

連続ジャンプは、3本から2本に減りました。3連続ジャンプが1本だけなのは、以前と同じです。

これまでは回転数が違えば別のジャンプとして数えましたが、今シーズンからは回転数にかかわらず3回までです。

同じ3回転・4回転を2回とも単独で跳んだ時に、2回目の基礎点が割り引かれる割合が小さくなりました。

フリーの3つのスピンのうち1つが、振り付けを見せるコレオスピンになりました。3回転以上続けて回れば姿勢は自由で、出来栄え点だけで評価されます。

連続ジャンプの間に挟む小さなジャンプ「オイラー」は、基礎点がなくなり（無得点）、ジャンプ要素の数に数えない「表外ジャンプ（除外ジャンプ）」になりました。

これまではオイラーも1つに数えたので、はさむと点のつくジャンプは2つまででした。今季は3つ跳べるので、オイラーを含む4連続ジャンプが可能です。使えるのはフリーだけで、1回までです。

  3. 同じ種類のジャンプは、回転数が違えば別のジャンプ。

  5. フリーのスピンのうち1つは、1つの姿勢のスピン。

Base values

スピン・ステップ・コレオの基礎点が上がりました。

ジャンプ以外の要素の基礎点が引き上げられました。例えば、足を換えるコンビネーションスピン（レベル4）は3.50から4.20になりました。

プラスαペアのフリーには、今シーズンから新しい要素として、コレオリフト（基礎点4.50）とコレオペアスピン（基礎点3.50）が加わりました。
