Program

プログラム中の要素は、種類と数が決まっています。

ショートプログラムには7つの要素があります。ジャンプが3つ（アクセル・単独のジャンプ・連続ジャンプ）、スピンが3つ、ステップシークエンスが1つです。連続ジャンプは、1つの要素として数えます。

フリースケーティングには11の要素があります。ジャンプが6つ（うち1つはアクセル）、スピンが3つ、ステップシークエンスとコレオシークエンスが1つずつ。連続ジャンプは2本まで入れられます。

今シーズンから、フリーのジャンプは7つから6つに減り、スピンのうち1つがコレオスピンになりました。

Element score

要素の点数は、基礎点と出来栄え点の合計です。

技術点は、プログラムの要素ごとの点数を合計したものです。要素の点数は、要素の種類と難しさで決まる基礎点に、出来栄え点（GOE：グレード・オブ・エグゼキューション）を加えて決まります。出来栄え点は、ジャッジがその要素の出来を評価してつける点です。

Base value

ジャンプの基礎点は、種類と回転数で決まります。

ジャンプは6種類あり、同じ種類でも回転数が1つ増えるごとに基礎点は大きく上がります。前向きに踏み切るアクセルだけは、ほかのジャンプより半回転多く回ります。

Grade of execution

要素の出来栄えは、−5から+5の11段階で評価されます。

ジャッジは要素ごとに、出来の良し悪しを11段階で評価します。1段階は基礎点の10%にあたるので、基礎点の高い要素ほど、出来栄えによる点の差も大きくなります。

プラスαジャッジは最大9人です。いちばん高い評価といちばん低い評価を1つずつ除き、残りの平均で出来栄え点が決まります。

Program components

演技構成点（PCS）は、3つの項目から構成されています。

演技構成点は、要素ごとの点数とは別に、ジャッジが演技全体を評価する点です。構成・表現・スケーティングスキルの各項目を、0.25から10まで0.25刻みで評価します。

  1. 構成0.25〜10
  2. 表現0.25〜10
  3. スケーティングスキル0.25〜10

Highlight

4回転か、3回転の出来栄えか。

成功が難しくても選手が4回転に挑むのは、基礎点が大きく違うからです。4回転ルッツは、3回転ルッツのほぼ2倍です。

出来栄えは−5から+5まで。1段階で基礎点の10%ずつ上下するので、4回転の方が上下の幅も大きくなります。

4回転ルッツは出来栄えが−2でも、3回転ルッツを+4の出来で跳んだときより点が高くなります。

ただし転倒すると、出来栄えが5段階下がり、さらに1点減点されます。

4回転を入れるか、3回転の出来栄えを上げるか。選手は、4回転をどれだけ確実に跳べるかで作戦を決めます。

女子のトリプルアクセル

女子のショートでは、単独のジャンプも連続ジャンプも3回転までで、4回転は入れられません。その中で、必ず1つ入れるアクセルは3回転半まで跳べます。ダブルアクセル（2回転半）ではなくトリプルアクセル（3回転半）を跳べば、この1本だけで基礎点が4.70上がり、ショートで狙える技術点が大きく変わります。

連続ジャンプの2本目

連続ジャンプの2本目をトウループからループに変えると、基礎点が上がります。ループはつま先をつかず、着氷した足のまま踏み切るので、2本目に跳ぶのが難しいジャンプです。

構成が崩れた際のリカバリー

フリーには、連続ジャンプを2本まで入れられます。演技の後半ほど疲れて跳ぶのが難しくなるので、最初のジャンプを連続ジャンプにする選手が多くいます。

例の構成では、最初の連続ジャンプの2本目が跳べず、単独になりました。ループの4.90点がなくなります。

後半のルッツも単独のままだと、同じ3回転を単独で2回跳んだことになり、2回目の基礎点は80%に下がります。

そこで、後半のルッツに、跳びやすい3回転トウループをつけます。2回目の基礎点も下がりません。

後半のジャンプは基礎点が1.1倍なので、予定との差は0.28点まで縮まります。

このように、予定どおりに跳べなかったあとの構成を変えて、失う点を小さくすることを、リカバリーといいます。
